Portfolio Design Gallery

The Starting Point

One resume, one clean portfolio page. A simple card-based layout to get the content on screen and establish a baseline.

Original

Clean card-based layout with a dark navy header and teal accents. The starting point for all other designs.

Exploring Styles

With the content locked in, the next step was trying five different visual directions — each exploring a different layout, color scheme, and typographic approach.

Minimal

Stripped-back design with generous whitespace, thin typography, and zero visual clutter. Content speaks for itself.

Dark Mode

Developer-inspired terminal aesthetic with a dark background, monospace font, and neon green accents.

Gradient

Bold gradient hero section with frosted glass cards and vibrant, colorful skill tags throughout.

Sidebar

Two-column layout with a fixed sidebar for navigation and contact info, and a scrollable content area.

Retro

Newspaper-inspired design with serif typography, ruled lines, and a warm cream color palette.

Pushing Further

After the basics, the challenge was to push each design into more distinct territory — experimenting with unconventional layouts, strong themes, and bolder visual identities.

Brutalist

Raw, anti-design aesthetic with harsh borders, system fonts, and bold black-white-red contrast.

Timeline

Vertical timeline with alternating left-right entries connected by nodes. Experience flows chronologically.

Neon

Cyberpunk aesthetic on pure black with glowing neon pink and cyan text shadows and borders.

Pastel

Soft lavender, mint, and peach palette with rounded shapes and a friendly, approachable feel.

Magazine

Editorial spread with drop caps, pull quotes, multi-column text, and bold serif typography.

Blueprint

Technical schematic on blueprint blue with white grid lines, dashed borders, and monospace type.

ASCII

Text-file aesthetic with box-drawing characters, monospace font, and pre-formatted content blocks.

Bento

Apple-style mosaic grid with different-sized cards creating an asymmetric, modern layout.

Nature

Earth tones with forest green, warm brown, and cream. Organic shapes and leaf-inspired dividers.

Vaporwave

Purple-pink retrowave with perspective grids, glitch text effects, and 80s/90s nostalgia.

Going Wild

At this point, the goal shifted from "professional portfolio" to "how far can we take this?" — full-on themed experiences that break every convention.

Glitch

Corrupted, malfunctioning aesthetic with chromatic aberration, clip-path slicing, and scanline artifacts.

Matrix

Green code rain on black. Terminal prompts, blinking cursors, and everything in shades of phosphor green.

Comic Book

Pop art with speech bubbles, halftone dots, starburst headers, and bold primary colors. POW!

Windows 98

Classic desktop UI with draggable windows, blue title bars, 3D beveled borders, and a taskbar.

Combining Favorites

The final step was mashing together the most interesting elements — taking the Windows 98 chrome and filling it with ASCII box-drawing content, then iterating on the layout by borrowing the bento grid structure.

ASCII-98

Windows 98 desktop chrome meets green-on-black ASCII terminals. Box-drawing characters inside beveled windows.

ASCII-98 Classic

Notepad windows on a Win98 desktop. Cream-white content, black text, blue links — like the old internet.

ASCII-98 Bento

The Notepad-on-Win98 style rearranged into a bento mosaic grid — asymmetric windows of different sizes.

ASCII-98 Blueprint

Notepad bento layout with Projects and Certificates windows rendered as blueprint schematics on blue.
