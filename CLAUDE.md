# Portfolio Design Gallery

## Overview
A collection of portfolio webpage designs for Cameron Lee, built from resume content. Each design uses a radically different visual style — all HTML and CSS only, no JavaScript.

## Structure
- `index.html` — Landing page with a grid of cards linking to all designs
- `designs/` — 20 portfolio page variations (original, minimal, dark, gradient, sidebar, retro, brutalist, timeline, neon, pastel, magazine, blueprint, ascii, bento, nature, vaporwave, glitch, matrix, comic, windows98)
- `Cameron Lee Resume.pdf` — Source resume (excluded from git)

## Conventions
- All pages are pure HTML + CSS — no JavaScript
- No external dependencies or CDNs (except Google Fonts in some designs)
- Cameron's phone number must never appear in any file
- Each design file includes a "Back to designs" link to `../index.html`
- Resume content is consistent across all designs
